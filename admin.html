วิธีเชื่อมเพจ Facebook (ทำหลังซื้อโดเมน)
  1. มีเพจ Facebook ของ Gold Signal (สร้างฟรีที่ facebook.com/pages/create)
  2. developers.facebook.com → สร้างแอป (Business) → เพิ่มสิทธิ์ pages_manage_posts, pages_read_engagement
  3. Graph API Explorer → เลือกเพจ → สร้าง Page access token แบบอายุยาว → คัดลอก Page ID และ token
  4. ใส่ใน Vercel (ทีม thander1 → gold-signal → Settings → Environment Variables, Production, Sensitive): FB_PAGE_ID และ FB_PAGE_TOKEN แล้วบอกผมให้ redeploy — อย่าวาง token ในแชท
